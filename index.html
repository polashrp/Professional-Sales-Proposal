⚙️ How to use

From install to signed proposal in 7 steps.

Install the template from Zoho Marketplace

Open Zoho CRM → Setup → Templates → Mail Merge Templates

Create a new Mail Merge Template for the Deals module

Select this Professional Sales Proposal Template

Open any Deal record and run Mail Merge

Proposal generates with client & deal data pre-filled

Review, export to PDF, and send to your client

📋 Requirements

  • Zoho CRM account
  • Zoho Writer access
  • Deals, Contacts & Accounts modules
  • Permission to create Mail Merge Templates
